Proofr's built-in mode uses Chrome's own AI model, which only runs on some desktop computers. See Chrome's requirements.

Connect any OpenAI-compatible AI provider below instead. Groq has a free tier and takes about a minute:

  1. Open console.groq.com/keys and sign in.
  2. Click Create API Key and copy it.
  3. Paste it in the API key field below and press Save.
